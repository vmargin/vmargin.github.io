# Historical Hero-Pair Design Material

This directory preserves reference frames, prompts, and measurements from an earlier October 2026 portfolio design. It does **not** describe the current hero layout.

The current portfolio uses the supplied portrait assets and layout defined by `src/data/portfolio.json` and the React components. Current source artwork lives under `assets/source/`; optimized application images live under `public/images/`. [Evidence sources](../../docs/evidence-sources.md) records their provenance.

## Retained historical material

- `reference/` contains comparison frames and portrait-alignment captures from the earlier design. These are design references, not current application screenshots.
- `prompts.json` records the earlier image-generation trial. Prompt text does not establish that an image is used by the current site.
- `measurements.json` records the earlier fit, hashes, and browser observations. Fields called `currentApplicationPair` describe the application **at the time of that record**, not the latest layout.
- Historical full-scene originals remain under `assets/source/hero-pair/`, with optimized copies under `public/images/projects/`. Source artwork is retained for provenance and reproducibility.

Personal workstation paths are omitted from public documentation. Recorded source hashes remain unchanged. This material is retained because historical design records reference it.
